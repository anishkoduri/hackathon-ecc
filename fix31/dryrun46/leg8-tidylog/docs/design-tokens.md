# TidyLog — design direction (dry-run #46 design leg)

Brief: a dev-tool landing page for TidyLog, a CLI + web viewer that turns messy
service logs into searchable timelines. One page: hero, three features, one
figure, footer. Palette-first inventory consulted in order — GetLayers FIRST,
then GSAP, React Bits, Hairline.

## Palette

- Ground: ink navy `#0b1020` / `#141a33`; paper `#f4f1e8`; signal lime `#b8f135`;
  mist `#9aa3b8`. Type: system sans + ui-monospace for terminal copy.
- Depth: flat with one WebGL ground (the Soffit gradient is the surface's one
  WebGL-heavy effect, WEBGL_ONE_F22). Motion: entrance 0.6s power2.out,
  stagger 0.04s, section reveal 0.5s power2.out.

| Source | Component | Tailoring |

## GetLayers layers — USED or CONSIDERED-AND-REJECTED (D19 reason each)

- **USED — Soffit (Gradients, Free).** D19: the hero needed a pointer-reactive
  ground that reads as "light over a dark workspace", and Soffit's composition
  (one long fall from an opening into shade, bounce lifting the deep end) is
  exactly a log tail's shape — bright recent lines falling into older shade.
  Live source: `https://getlayers.ai/layer/soffit`, consulted 2026-11-17 from
  `llms.txt` (62 templates / 222 3D scenes / 54 sections / 530 backgrounds /
  1,088 gradients) + the `/gradients` category page.
- **CONSIDERED-AND-REJECTED — Tress (Gradients, Flow family).** D19: a flowing
  gradient's motion fights the brief — TidyLog is about stillness and order,
  not flow; the Shadow family's fall-into-shade reads as a workspace, Flow
  reads as decoration.
- **CONSIDERED-AND-REJECTED — any 3D Scene.** D19: the Soffit gradient already
  spends this surface's one WebGL-heavy effect (WEBGL_ONE_F22); a real-time 3D
  scene on the same hero would be a second heavy effect and would bury the
  terminal card, which is the proof of the product.
- **CONSIDERED-AND-REJECTED — any page Template.** D19: a full-page template
  would override the brief's own layout (hero + three features + figure); the
  brief is a small landing page, and the template's sections would be cut
  rather than used — a foundation, not a finished brand, means taking the
  ground, not the page.

## GetLayers prompt note (honest)

The Soffit layer's copyable prompt is generated by the layer page's "Copy
prompt" button at click time — it is not exposed in the page text fetched by
`browser.open` or in the page HTML fetched by curl (verified: the HTML carries
the description and the FAQ text, no prompt field). The rebuild in
`SoffitGradient.tsx` is therefore built from the layer's published description
(quoted in the file header), not from a verbatim copied prompt. The layer was
still consulted live FIRST, and the rebuild keeps its composition and motion.

## Reduced-motion fallback

GSAP tweens are skipped when `prefers-reduced-motion: reduce` (content visible
at rest); Soffit draws one static frame and never starts its loop; SplitText
renders the whole headline. Verified by code inspection (no reduced-motion
browser run in this leg).
