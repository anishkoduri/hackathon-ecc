## Method note — what counts as an invocation

- **Strong:** backticked `` `name` ``, `skill:name`, a path (`skills/<name>/`, `agents/<file>.md`, `commands/<name>.md`, a relative `../<name>/SKILL.md` link), a `/command` slash form, a `<stem>.mdc` link, a double-quoted `"name"` (len >= 3), a bare name in a SKILL.md / agent frontmatter `description:` (Cursor reads descriptions to route), a name adjacent to the word `skill`/`agent` (`<name> skill`, `skill <name>`), or a hooks.json registration.
- **Backtick handling:** `` ``double-backtick spans`` `` are unpacked before single-backtick extraction; a naive regex pairs the wrong backticks after a double span and corrupts every token after it (found in `rules/common-agents.mdc`).
- **Inventory:** listed in `references/design-inventory.md` — the design-lead reads it before deciding, so a listing is a routing path for design skills.
- **Trigger:** a `skill:<name>` key in `manifests/context-packs/skill-triggers@1.json` routes user phrasing to the skill.
- **Structural:** a rule's `alwaysApply` / `globs` (Cursor auto-applies it); a command's existence in `commands/` (the user can type `/name`); a hook's hooks.json registration (Cursor fires the event).
- **Shipped** (install manifests list the name) is recorded but does NOT count as an invocation. **Weak** (bare-word match) is recorded but NEVER sufficient on its own — generic names match ordinary prose.
- An element's own definition files never count as invokers of itself. This file (`call-map.md`) never counts as an invoker.
- Tables show only real invokers (strong / inventory / trigger / structural) for called elements; weak and shipped evidence is in `fix28/callmap/call-map-data.json`. Uncalled elements show all evidence found, so the reader can see what was ruled out. Invokers from staged sources are marked `(staged)` — the staged file and its built copy are distinct files with the same tail.

- **B3 — references by description** ("the blind reviewer") are not matched; only literal names and paths are.
- **B4 — bare agent names** ("ask the architect") are weak-only and do not count as a call.
- **B5 — scripts/hooks/:** only the 15 hooks.json entries count as hooks. Unreached files under `scripts/hooks/` are upstream ECC machinery, not counted hooks.

Those loader files were removed as dead weight in fix #28, so the chain does not exist in this tree at all.
